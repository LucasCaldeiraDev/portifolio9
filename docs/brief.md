# Brief — Obra Viva

## O que é

Landing page imersiva de um empreendimento imobiliário fictício ("Edifício Vértice"),
criada como peça de portfólio de Lucas Caldeira Pires. O conceito central: o scroll
literalmente constrói o prédio — terreno vazio → fundação → estrutura → fachada →
edifício entregue.

Todo conteúdo comercial (nome, números, prazos) é fictício e está sinalizado como
estudo de portfólio na própria página.

## Público

1. Recrutadores e clientes avaliando o portfólio do autor (público real).
2. "Comprador de apartamento" (público encenado, para quem a narrativa é escrita).

## Objetivo e CTA

- Objetivo real: demonstrar domínio de animação por scroll, direção visual e craft.
- CTA primário (encenado): "Quero conhecer o Vértice" → âncora para contato.
- CTA real: bloco do autor com GitHub e e-mail.

## Objeções a responder

- "Animação por scroll costuma ser pesada/travada" → performance budget + fallbacks.
- "É só efeito?" → conteúdo essencial em HTML, acessível sem animação.
- "Funciona no celular?" → pin reduzido, cena adaptada, testado em viewport mobile.

## Mensagem-núcleo

Acompanhe a obra do seu futuro endereço, etapa por etapa — a página é o canteiro.
